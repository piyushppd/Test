# Test

Minimal repo with an example Jupyter Notebook. Useful to test opening a notebook locally or in Google Colab.

## Overview

- Contains a sample notebook: Welcome_To_Colaboratory.ipynb
- Demonstrates basic Colab/Notebook usage.

## Quick Start

Option A: Open in Google Colab
- Upload Welcome_To_Colaboratory.ipynb to https://colab.research.google.com and open it.

Option B: Open locally
- Prerequisites: Python 3.x and Jupyter (or VS Code with the Jupyter extension).
- Install Jupyter: pip install jupyter
- Launch: jupyter notebook and open Welcome_To_Colaboratory.ipynb
